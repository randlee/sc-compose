## Description

Agent level: normal.
### Deliverables
1. FR-26: consume V4's working generic live-Clap model exporter. Adopt pinned external docli (crate sc-docli, executable docli) and implement scripts/generate_cli_reference.py as a thin generate/check wrapper. Every planned consumer publish path has the declared check. The reusable side is complete and tested; final actual-command reference files and integrated passing preflight close in V6.

- python3 plugins/sc-publish/install.py --dry-run --input release/sc-publish-install.json . (canonical installer convergence).
- python3 -m unittest discover -s .github/scripts/tests -p test_install.py; python3 -m unittest discover -s .github/scripts/tests -p test_publish_kit_scripts.py; python3 -m unittest discover -s scripts/tests -p test_generate_cli_reference.py (V8 adds this wrapper test).

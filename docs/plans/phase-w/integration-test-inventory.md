## Revised sprint scope (Rand, 2026-11-16)

W-5 builds a local-first, end-to-end Python suite using the installed bd 1.3.4 or randlee/beads fork and installed Dolt. One `just integration` command creates a throwaway server-mode database, exercises the actual CLI across all pour/repour paths, verifies persisted bd state after each step, and tears the server down. It writes a dated XHTML report and index entry with a panel per target, bd version and mode, including the bd executable SHA-256, Dolt version and per-scenario results. Bugs found are fixed with suite and unit regressions. The dedicated server CI job is removed; ordinary CI remains simple.

Local runs on a temporary database are first. Only heavy load tests are prohibited locally; use serial bounded tests with no stress, soak or parallel fan-out, and never use the shared server or port 3308. W-6 fuzzes against the same setup after w-5 integration and fixes pass. W-7 follows w-6 and adds an optional install step for an atmbench account on this computer or on Colima, where embedded and server modes can also be tested. Neither later sprint is built in w-5.

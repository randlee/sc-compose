File: crates/sc-compose/src/reporting/path.rs

Overview

resolve_relative_path is an Application-layer path resolver that consumes a workspace root and report path, producing a canonical absolute PathBuf for reporting commands. It resolves relative paths against the workspace root, leaves absolute inputs rooted as provided, and converts filesystem-resolution failures into configuration-parse usage errors.

Public API

resolve_relative_path

pub(crate) fn resolve_relative_path(
    workspace_root: &Path,
    path: &Path,
) -> Result<PathBuf, CommandError>

Returns the canonical filesystem path for path.

  • Relative paths are joined to workspace_root.
  • Absolute paths are used directly.
  • The resulting path is canonicalized, so it must exist and the returned value has normalized filesystem components.
  • Canonicalization failures become CommandError::usage_with_code errors with DiagnosticCode::ErrConfigParse and context identifying the path that could not be resolved.

The function is crate-visible and is used by reporting::init::run_smoke_report and reporting::spec::run_render_spec_report.

Dependencies

  • std::path::{Path, PathBuf} supplies the input and resolved-path types.
  • std::fs::canonicalize validates and canonicalizes the selected path.
  • anyhow::anyhow adds contextual error information.
  • sc_composer::DiagnosticCode classifies failures as ErrConfigParse.
  • crate::CommandError adapts resolution failures into CLI/application usage errors.

The test module uses temporary directories and files to verify both relative and absolute input behavior.

Usage Notes

Reporting workflows should pass the workspace root together with a user-supplied report path before reading report inputs. This ensures relative configuration paths are interpreted consistently from the workspace rather than the process working directory.

Because canonicalization is performed, callers cannot use this helper for paths that have not been created yet. Missing paths, inaccessible paths, and invalid path components produce a configuration-parse usage error.

Tests cover:

  • Resolving reports/smoke/sample.txt relative to a temporary workspace root.
  • Preserving an already canonical absolute path.

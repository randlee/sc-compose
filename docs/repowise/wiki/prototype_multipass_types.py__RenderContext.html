Symbol: prototype.multipass.types.RenderContext

Purpose

RenderContext stores the values available during one template-rendering pass in the multipass prototype. It pairs the current pass number with a mutable dictionary of render variables.

Signature

@dataclass
class RenderContext:
    pass_number: int
    variables: dict[str, Any] = field(default_factory=dict)

Parameters

  • pass_number: int
    The ordinal number of the current rendering pass.

  • variables: dict[str, Any]
    Variables supplied to that pass. Defaults to a new empty dictionary for each instance.

Returns

Constructing RenderContext returns a context object with:

  • pass_number set to the provided pass identifier.
  • variables set to the supplied mapping or a fresh empty dictionary.

Because variables uses default_factory=dict, separate contexts do not share the same default dictionary.

Example Usage

from prototype.multipass.types import RenderContext

context = RenderContext(
    pass_number=1,
    variables={
        "environment": "production",
        "service_name": "api",
    },
)

assert context.pass_number == 1
assert context.variables["service_name"] == "api"

A later pass can use its own context and variable set:

next_context = RenderContext(
    pass_number=2,
    variables={"generated_config": "…"},
)

Input
background descendant inherits stdout, direct child floods past the 64 KiB cap
Expected
An over-limit command terminates every descendant holding captured output pipes and returns promptly.
Observed
The original runner killed only the direct PID, so the pipe remained open until the orphaned descendant exited.
Requirement / ADR
ADR-0021 requires bounded captured stdout/stderr and termination after an output cap breach.
Requirement / ADR follow-up
No new ADR is needed; the production fix must retain process-tree termination on Unix and Job Object containment on Windows.
Root cause
Direct-child-only termination did not close inherited pipe descriptors held by descendants.
Recommended fix
Terminate the process group on Unix and the assigned Job Object on Windows, with a regression proving prompt return.

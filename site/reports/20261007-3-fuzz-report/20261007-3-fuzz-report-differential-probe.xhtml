FUZZ-051

Minimal template / frontmatter
{"a":[1, 2]}
Input
destination absent
Expected
render.md 'Appending JSON records' step 3: 'writes it as one compact UTF-8 line (embedded newlines stay escaped) followed by \n'.
Observed
Exit 0; nl.jsonl holds 2 physical lines '{"a":[1,' and '2]}', neither valid JSON. Nested whitespace is kept ({"z":[1, 2]}); only the top level is compacted. The concurrent-append family did not hit this because its records keep nested values on one line.
Requirement / ADR
render.md steps 2-3; FR-7 render --append (JSON Lines)
Requirement / ADR follow-up
No new ADR needed.
Root cause
append_json_record re-serializes a BTreeMap<String, Box<RawValue>>, so each top-level value's raw text (including newlines and spaces) is written verbatim.
Recommended fix
Re-serialize nested values compactly while preserving number lexemes (e.g. serde_json arbitrary_precision Value), or minify RawValue text outside strings.

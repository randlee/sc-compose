FUZZ-038

Minimal template / frontmatter
n/a
Input
request path argv containing one non-UTF-8 byte (0xFF), file absent
Expected
help bead: request-file read failures use BEADS_REQUEST_READ_FAILED (exit 3) with details.path/kind and recovery; FR-7 stable envelope, never a panic. Baseline 080f261: exit 3 envelope.
Observed
Exit 101, empty stdout: thread 'main' panicked at crates/sc-composer-beads/src/error_json.rs:25:17: called Result::unwrap() on Err 'path contains invalid UTF-8 characters'. JSON and human mode. Coordinator 3/3; baseline exit 3.
Requirement / ADR
help bead Request-file read failures; ADR-0023 Request errors; FR-7
Requirement / ADR follow-up
No new ADR needed.
Root cause
impl Serialize for BeadComposeError builds json!({"path": path, ...}) for RequestReadFailed; json! unwraps serde_json::to_value(PathBuf), which fails for non-UTF-8 paths. Reached via print_json and human_bead_error.
Recommended fix
Serialize the path lossily (to_string_lossy) or as bytes and never unwrap in the error serializer.

FUZZ-040

Minimal template / frontmatter
formula u: step 'head', step 'tail' needs ['head']
Input
existing parent with bd-accepted id 'spc-$(id)58' (also 'spc-a;b90', 'spc-x"q65', ESC/bidi/C0 ids); attach, bd dep remove tail head, re-run
Expected
ADR-0023 Errors: GraphEdgeMissing recovery is 'run the bd dep add command the message gives'; the message lists 'the exact command'. help bead: each recovery command printed on its own line.
Observed
Printed 'bd dep add spc-$(id)58.rdollar_subshellv2-tail spc-$(id)58.rdollar_subshellv2-head --type blocks' unquoted: a shell runs `id`; ';' splits the command; quotes merge args; control/bidi characters reach the terminal raw. Receipt missing_edges data itself is correct. Coordinator 3/3.
Requirement / ADR
ADR-0023 Errors (GraphEdgeMissing); help bead human output
Requirement / ADR follow-up
No new ADR needed.
Root cause
Commands built with plain Display format!("bd dep add {} {} --type {}") with no shell quoting or control escaping; BeadId only forbids whitespace.
Recommended fix
Shell-quote each argument (and escape control characters) in the human and message forms, or reject such ids at BeadId.

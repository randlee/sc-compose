File: bindings/python/src/types/policy.rs

Overview

policy.rs is the Python Types-layer adapter that exposes validated sc_composer policy, mode, naming, confinement, and pass-configuration values as PyO3 classes. It consumes Python-facing inputs, converts them through shared coercion helpers, and produces wrapped Rust domain types with Python-friendly properties, exceptions, and representations.

The module defines wrappers for VariableName, ProfileName, ConfiningRoot, ResolverPolicy, ComposeMode, ComposePolicy, and PassConfig. These classes are registered by the Types module and are also returned by other binding types where policy data is exposed.

It keeps the Python API aligned with the Rust library while preserving domain validation: invalid variable names become validation errors, invalid profile/root configuration becomes configuration errors, and path-resolution failures become composed Python exceptions.

Public API

  • VariableName(value)
  • Validates and wraps sc_composer::VariableName.
  • str(value) returns the raw name.

  • repr(value) is VariableName("...").

  • ProfileName(value)

  • Validates and wraps sc_composer::ProfileName.
  • Uses configuration-oriented errors for invalid names.

  • Provides Python str and repr.

  • ConfiningRoot(path)

  • Accepts a path-like Python value and constructs a confinement root.
  • confine(candidate) resolves a candidate template path through sc_composer::resolve_template_path and returns its resolved path as a string.

  • str(root) returns the root path.

  • ResolverPolicy

  • Read-only wrapper returned from ComposePolicy.resolver_policy.

  • Its representation reports counts of candidate directories and filename probes plus ambiguity behavior.

  • ComposeMode

  • ComposeMode.file(template_path) creates file-based composition mode.
  • ComposeMode.profile(kind, name) creates profile-based composition mode after parsing the profile kind and name.

  • Properties:

    • template_path: path for file mode; otherwise None.
    • kind and name: profile details for profile mode; otherwise None.

  • ComposePolicy(...)

  • Constructor defaults:
    • strict_undeclared_variables=False
    • unknown_variable_policy="ignore"
    • max_include_depth=32
    • allowed_roots=None
    • passes=None
  • Parses the unknown-variable-policy string, extracts allowed roots and pass configurations, and initializes the resolver policy with Rust defaults.

  • Properties expose strict-variable behavior, policy name, include depth, allowed roots, resolver policy, and pass configurations.

  • PassConfig(pass_number, required_variables=None, defaults=None, metadata=None)

  • Converts Python collections into the corresponding Rust pass configuration.
  • A pass_number of 0 is replaced with the library default pass number.
  • Properties expose required variables and convert stored JSON/default metadata back into Python dictionaries.

Internal helpers python_string_repr, python_option_string_repr, and python_bool_repr standardize Python-style repr output. compose_mode_repr and compose_policy_repr provide the representations consumed by the wrapper classes and request-related tests.

Dependencies

  • sc_composer
  • Supplies the underlying domain types (ComposeMode, ComposePolicy, PassConfig, ConfiningRoot, and naming types).

  • Resolves confined template paths for ConfiningRoot.confine.

  • pyo3

  • Defines Python classes, constructors, getters, Python object handling, and PyDict construction.

  • crate::convert

  • Coerces path-like values and extracts Python collections into Rust roots, variables, maps, metadata, profile names, and pass configurations.

  • Converts JSON values back to Python objects.

  • crate::enums

  • Parses Python policy/profile strings and renders canonical strings for getters and representations.

  • crate::errors

  • Maps validation, configuration, and composition failures to Python exceptions.

  • types::mod

  • Registers these wrappers into the Python extension module.

  • types::results

  • Consumes policy-related wrapper types as part of the neighboring Types-layer API.

Usage Notes

Use these classes when constructing Python binding requests instead of manually assembling Rust-domain equivalents. Constructors intentionally accept Python-native values—such as strings, path-like objects, sequences, mappings, and dictionaries—and delegate validation/conversion to the shared binding helpers.

ConfiningRoot.confine performs actual resolution under the root; it is more than a string join and can raise a composition error when the candidate is invalid or escapes the permitted scope.

ComposeMode is a tagged union represented through factory methods. Check template_path for file mode or kind/name for profile mode; non-applicable properties return None.

ComposePolicy.resolver_policy and ComposePolicy.passes return cloned wrapper values. Mutating a returned Python object does not mutate the original policy instance.

defaults and metadata on PassConfig are reconstructed as Python dictionaries on access. Metadata conversion may fail if an internal metadata value cannot be serialized to JSON.

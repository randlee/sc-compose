Overview

Application-layer edge connector enums.rs adapts sc_composer enum values into Python-facing string constant classes and converts Python inputs back into core enum types.

It registers six PyO3 classes—RuntimeKind, ProfileKind, UnknownVariablePolicy, VariableSource, DiagnosticSeverity, and DiagnosticCode—on the extension module. The file also centralizes bidirectional mappings between selected sc_composer enums and their stable Python string representations.

Invalid runtime kinds, profile kinds, and unknown-variable policies are reported through the binding layer’s ScConfigError constructor rather than raw conversion errors.

Public API

All Rust items are pub(crate), but register exposes the following Python classes when invoked by the module initializer:

Python class Constants
RuntimeKind CLAUDE, CODEX, GEMINI, OPENCODE
ProfileKind AGENT, COMMAND, SKILL
UnknownVariablePolicy ERROR, WARN, IGNORE
VariableSource EXPLICIT_INPUT, ENVIRONMENT, BUILTIN, TEMPLATE_INPUT_DEFAULT, FRONTMATTER_DEFAULT, INCLUDED_DEFAULT
DiagnosticSeverity ERROR, WARNING, INFO
DiagnosticCode Resolver, include, validation, rendering, and configuration diagnostic-code strings

Key functions:

  • register(module) adds all six Python classes to a PyModule.
  • parse_runtime_kind(value) extracts a Python string and returns RuntimeKind.
  • parse_profile_kind(value) extracts a Python string and returns ProfileKind.
  • parse_unknown_variable_policy(value) converts a Rust string to UnknownVariablePolicy.
  • runtime_kind_str, profile_kind_str, unknown_variable_policy_str, variable_source_str, and diagnostic_severity_str serialize core enum values to canonical static strings.

Dependencies

  • pyo3::prelude::* supplies Python binding types, #[pyclass], #[pymethods], and module registration support.
  • sc_composer supplies the domain enums: RuntimeKind, ProfileKind, UnknownVariablePolicy, VariableSource, and DiagnosticSeverity.
  • crate::errors::config_error converts invalid binding inputs into the package’s configuration exception.

Consumers include:

  • convert.rs, whose runtime extraction path calls parse_runtime_kind.
  • types/policy.rs, which uses profile and unknown-variable-policy parsing.
  • types/results.rs, which uses the string serializers for Python result objects.
  • lib.rs, which invokes register during Python module setup.

Usage Notes

Use the Python class constants instead of hard-coded literals when constructing API inputs:

from sc_compose import RuntimeKind, UnknownVariablePolicy

runtime = RuntimeKind.CODEX
policy = UnknownVariablePolicy.WARN

The parser functions accept only the documented lowercase strings. Unknown values produce ScConfigError messages such as unknown runtime kind: <value> or unknown unknown-variable policy: <value>.

The string serializer functions are intentionally exhaustive over their corresponding Rust enums; add a matching parser arm, serializer arm, and Python class constant whenever a supported enum variant becomes part of the Python API.

Getting Started

I’ll ground this strictly in the supplied README excerpts and repository onboarding rules.

Prerequisites

  • Git
  • A recent Rust toolchain with Cargo, for building from source
  • Python, if working with the Python bindings

Clone & install

  1. Clone the repository and enter the checkout.

sh git clone <repository-url> cd repowise-analysis

  1. Build the CLI from source.

sh cargo build --release -p sc-compose

Run

The CLI entry point is crates/sc-compose/src/main.rs.

cargo run -p sc-compose --

Library entry points include crates/sc-composer/src/lib.rs and bindings/python/src/lib.rs.

Test

cargo test --workspace

Troubleshooting

  • cargo install sc-compose ships only the binary; set SC_COMPOSE_DATA_DIR to use examples.

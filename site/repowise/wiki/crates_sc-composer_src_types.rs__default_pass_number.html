Symbol: crates.sc-composer.src.types.default_pass_number

Purpose

default_pass_number provides the canonical default rendering pass for frontmatter and pass-policy entries. It returns pass 1, ensuring that omitted pass values have a consistent, predictable meaning throughout sc-composer.

The function is marked #[must_use], so callers should not ignore its result.

Signature

pub const fn default_pass_number() -> u8

Parameters

This function takes no parameters.

Returns

Returns a u8 with the value 1.

Because it is a const fn, it can be used both at runtime and in constant expressions.

Example Usage

use sc_composer::types::default_pass_number;

let pass = default_pass_number();

assert_eq!(pass, 1);

It can also be used when defining a compile-time default:

use sc_composer::types::default_pass_number;

const INITIAL_PASS: u8 = default_pass_number();

assert_eq!(INITIAL_PASS, 1);

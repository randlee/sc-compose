Overview

errors.rs is the Application-layer edge connector that translates sc_composer failures into typed Python exceptions with message and optional diagnostic code attributes. It defines a Python exception hierarchy rooted at ScComposeError, registers those classes on the extension module, and preserves domain-specific error categories for Python callers.

Public API

Python-visible exception classes:

  • ScComposeError: base exception extending Python’s Exception; exposes read-only message: str and code: str | None.
  • ScRenderError
  • ScValidationError
  • ScResolveError
  • ScIncludeError
  • ScConfigError

Each subclass extends ScComposeError and accepts (message, code=None).

Crate-internal integration functions:

  • register(module): adds all exception classes to the Python module.
  • compose_error_to_pyerr(error): dispatches each ComposeError variant to its corresponding Python exception.
  • resolve_error_to_pyerr, include_error_to_pyerr, validation_error_to_pyerr, render_error_to_pyerr, config_error_to_pyerr: convert specific composer errors.
  • validation_error and config_error: construct categorized Python errors directly from dynamic messages and optional codes.

Dependencies

  • pyo3: declares Python classes, inheritance, constructors, module registration, and PyErr creation.
  • sc_composer: supplies ComposeError and its resolve, include, validation, render, and configuration error types, including diagnostic codes.
  • Dependent Python-binding modules such as functions, convert, enums, and request/result/policy types use these conversion helpers to expose consistent failures at the binding boundary.

Usage Notes

Call register while initializing the Python extension module so the exception types are importable and catchable from Python.

Use compose_error_to_pyerr at boundaries that return a general ComposeError; it retains the concrete category instead of collapsing all failures into the base class. Use the specialized conversion helpers when a function already has a concrete composer error type.

The converter copies the domain error’s message and diagnostic code into Python-visible attributes. Render errors may omit a code, while the other mapped error categories always pass their diagnostic code.

Tests verify both attribute visibility and that a missing-template resolution failure becomes ScResolveError with ERR_RESOLVE_NOT_FOUND.

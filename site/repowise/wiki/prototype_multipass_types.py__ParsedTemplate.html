Symbol: prototype.multipass.types.ParsedTemplate

Purpose

ParsedTemplate represents a template after its stacked pass headers have been separated from its renderable body. It keeps the remaining render-pass metadata alongside the body text so parsing, rendering, validation, and deployment checks can operate on one value.

The class is a dataclass with two convenience properties:

  • pass_count reports how many render passes remain.
  • is_fully_rendered reports whether no passes remain and the template is ready for deployment.

Signature

@dataclass
class ParsedTemplate:
    passes: list[PassHeader]
    body: str

    @property
    def pass_count(self) -> int: ...

    @property
    def is_fully_rendered(self) -> bool: ...

Parameters

  • passes: list[PassHeader]
    The ordered collection of parsed pass headers still associated with the template. Each header describes a rendering pass that must be applied before the template is complete.

  • body: str
    The template content after its stacked headers have been parsed out.

Returns

Constructing ParsedTemplate returns an object containing the parsed headers and body.

Its properties return:

  • pass_count -> int
    The number of entries in passes.

  • is_fully_rendered -> bool
    True when passes is empty; otherwise False.

Example Usage

from prototype.multipass.types import ParsedTemplate, PassHeader

template = ParsedTemplate(
    passes=[
        PassHeader(name="base"),
        PassHeader(name="environment"),
    ],
    body="service: {{ service_name }}",
)

assert template.pass_count == 2
assert template.is_fully_rendered is False

# After all pass headers have been consumed by rendering:
rendered = ParsedTemplate(
    passes=[],
    body="service: catalog",
)

assert rendered.pass_count == 0
assert rendered.is_fully_rendered is True

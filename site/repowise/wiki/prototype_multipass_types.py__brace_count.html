Symbol: prototype.multipass.types.PassHeader.brace_count

Purpose

brace_count exposes the number of opening and closing braces used to delimit variables for a given multipass rendering stage.

It derives the delimiter width from pass_number:

  • Pass 1 uses {{ variable }}
  • Pass 2 uses {{{ variable }}}
  • Pass 3 uses {{{{ variable }}}}

This allows each pass to target only the template expressions intended for that stage.

Signature

@property
def brace_count(self) -> int

Qualified name: prototype.multipass.types.PassHeader.brace_count

Parameters

This property accepts no explicit parameters.

It reads self.pass_number, which identifies the current rendering pass.

Returns

Returns an int equal to self.pass_number + 1.

The returned value is the number of braces required on each side of a variable delimiter for the current pass.

pass_number brace_count Variable syntax
1 2 {{ variable }}
2 3 {{{ variable }}}
3 4 {{{{ variable }}}}

Example Usage

from prototype.multipass.types import PassHeader

header = PassHeader(pass_number=2)

assert header.brace_count == 3

variable_name = "environment"
delimiter = "{" * header.brace_count

template_expression = (
    f"{delimiter} {variable_name} "
    f"{'}' * header.brace_count}"
)

assert template_expression == "{{{ environment }}}"

Because brace_count is a property, access it without parentheses.

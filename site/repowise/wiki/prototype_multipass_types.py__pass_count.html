Symbol: prototype.multipass.types.ParsedTemplate.pass_count

Purpose

ParsedTemplate.pass_count reports how many render passes remain in a parsed multipass template. It is a read-only property derived from the template’s passes collection.

Signature

@property
def pass_count(self) -> int

Parameters

This property takes no explicit parameters.

  • self: The ParsedTemplate instance whose remaining passes are counted.

Returns

Returns an int equal to the number of entries in self.passes.

  • 0 means no render passes remain.
  • A positive value indicates the number of passes still available.

Its implementation is constant in structure and delegates the count to Python’s len:

return len(self.passes)

Example Usage

from prototype.multipass.types import ParsedTemplate

parsed = ParsedTemplate(
    # ... template fields ...
    passes=["first-pass", "second-pass"],
)

if parsed.pass_count > 0:
    print(f"{parsed.pass_count} render passes remaining")

Example output:

2 render passes remaining

Because pass_count is a property, access it without parentheses:

remaining = parsed.pass_count

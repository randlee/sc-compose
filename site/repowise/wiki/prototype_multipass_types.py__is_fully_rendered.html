Symbol: prototype.multipass.types.ParsedTemplate.is_fully_rendered

Purpose

is_fully_rendered reports whether a ParsedTemplate has completed all remaining render passes and is ready for deployment. It is a read-only boolean property.

Signature

@property
def is_fully_rendered(self) -> bool

Parameters

This property takes no explicit parameters.

It evaluates the instance’s passes collection.

Returns

bool

  • True when self.passes is empty, meaning no rendering passes remain.
  • False when one or more passes are still pending.

Its behavior is equivalent to:

len(self.passes) == 0

Example Usage

template = ParsedTemplate(
    # ...
    passes=[],
)

if template.is_fully_rendered:
    deploy(template)
else:
    continue_rendering(template)

A template with pending work is not fully rendered:

template.passes = ["resolve_environment_values"]

assert template.is_fully_rendered is False

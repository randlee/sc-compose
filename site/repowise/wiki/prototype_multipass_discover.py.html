File: prototype/multipass/discover.py

Overview

prototype.multipass.discover is an Application-layer token discovery adapter that consumes multipass Jinja-like template text and parsed pass metadata to produce per-pass sets of referenced variable names. It selects the native sc_compose scanner for safe standard {{ ... }} templates and uses a brace-aware Python scanner for triple-or-higher delimiters, while tracking loop bindings so local variables are excluded.

Public API

  • discover_tokens(text: str, brace_count: int) -> set[str]
    Finds variable references for one delimiter width. brace_count must be at least 2. For ordinary double braces without higher-brace sequences, delegates to sc_compose.discover_tokens; otherwise uses the local scanner.

  • discover_all_tokens(parsed: ParsedTemplate) -> dict[int, set[str]]
    Iterates parsed.passes and returns a mapping from each pass number to tokens found in parsed.body using that pass’s brace count.

  • LoopScope(bound_names: set[str])
    Represents loop-local names introduced by {% for ... %} statements. Active scopes prevent loop variables from being reported as external references.

Internal helpers coordinate the fallback scanner:

  • _find_delim and _find_close_delim reject delimiter matches embedded in a longer brace sequence.
  • _parse_for_scope extracts loop bindings and records identifiers used by the iterable expression.
  • _collect_identifiers recognizes dotted or hyphenated identifiers, excludes Jinja keywords, and filters names bound in active loop scopes.

Dependencies

  • sc_compose supplies the native double-brace token discovery binding.
  • .types.ParsedTemplate supplies pass headers, including pass_number and brace_count.
  • Python re provides identifier matching.

Callers include the multipass test modules and validate_passes. discover_all_tokens calls discover_tokens, which either invokes the native binding or routes to _discover_tokens_py; the fallback scanner in turn uses delimiter, loop-scope, and identifier-collection helpers.

Usage Notes

Use discover_tokens when validating or inspecting one rendering pass:

tokens = discover_tokens(template_body, brace_count=3)

Use discover_all_tokens when a ParsedTemplate contains multiple pass declarations:

tokens_by_pass = discover_all_tokens(parsed_template)

The scanner treats {% ... %} blocks consistently across passes, skips {# ... #} comments, recognizes identifiers in expressions, and excludes Jinja keywords such as if, for, true, and loop. Loop-local bindings are not emitted, but identifiers used to construct a loop iterable are.
